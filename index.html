PROYEK UNGGULAN

Implementasi Server Cloud Menggunakan ownCloud

Proyek tugas akhir Universitas Mercu Buana 2026

Implementasi layanan private cloud berbasis ownCloud dengan integrasi Collabora dan ONLYOFFICE untuk mendukung penyimpanan serta kolaborasi dokumen melalui server yang dikelola sendiri.

Tujuan

Membangun layanan penyimpanan file terpusat dan mengeksplorasi kolaborasi dokumen melalui integrasi aplikasi perkantoran berbasis web.

Arsitektur

ownCloud sebagai layanan penyimpanan, dengan Collabora dan ONLYOFFICE sebagai komponen kolaborasi dokumen sesuai konfigurasi dan skenario pengujian proyek.

Implementasi

  • Persiapan lingkungan server dan kebutuhan sistem.
  • Instalasi serta konfigurasi ownCloud.
  • Integrasi layanan Collabora dan ONLYOFFICE.
  • Konfigurasi akses dan pengujian fungsi sistem.

Pengujian

  • Akses pengguna dan pengelolaan file.
  • Pembukaan dan pengeditan dokumen.
  • Pengujian integrasi berdasarkan skenario yang dilakukan.
  • Dokumentasi hasil pengujian aktual.
